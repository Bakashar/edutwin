# EduTwin.kz — Цифровой Двойник Ученика v2.0

Многоагентная EdTech-система для подготовки к ЕНТ Казахстана.

## ✨ Что нового в v2.0

### 📚 Мультипредметность
- **12 предметов ЕНТ**: Математика, Физика, Химия, Биология, История Казахстана, Всемирная история, География, Информатика, Английский язык, Русский язык, Математическая грамотность, Грамотность чтения
- **Банк вопросов**: 75+ вопросов с объяснениями по всем предметам
- **Диагностика** охватывает все выбранные предметы (2 вопроса на предмет)

### 🎯 Выбор предметов
- Экран выбора предметов перед диагностикой
- 4 обязательных + профильные на выбор
- Счётчик времени диагностики

### 📊 Улучшенный дашборд
- Вкладки: «Обзор» и «По предметам»
- Прогресс-бары по каждому предмету
- Сильные/слабые темы в разрезе предмета
- Статистика subjectStats в профиле

### 🤖 Улучшенные AI-агенты
- Все 6 агентов переработаны под мультипредметность
- AlemLLM теперь поддерживает все предметы на казахском
- Более точные промпты по программе НЦТ

### 🎨 Новый UI
- Шрифт Manrope (заменил Inter)
- Прогресс диагностики в шапке чата
- Анимированные кнопки выбора предметов
- Улучшенная цветовая схема

## 🏗️ Архитектура

```
src/
├── App.tsx                  # Главный компонент (новая фаза subject-select)
├── types.ts                 # Типы (+ Subject, SubjectStats)
├── constants.ts             # 75+ вопросов по 12 предметам + утилиты
├── index.css                # Manrope + кастомные анимации
├── components/
│   ├── SubjectSelector.tsx  # 🆕 Экран выбора предметов
│   ├── ChatWindow.tsx       # Чат (+ прогресс диагностики)
│   └── StudentDashboard.tsx # Дашборд (+ вкладка «По предметам»)
└── services/
    └── aiService.ts         # 6 агентов + улучшенные промпты + AlemLLM
```

## 🚀 Запуск

```bash
# Frontend
cp .env.example .env
# Заполнить .env: VITE_QWEN_API_KEY, VITE_ALEMLLM_API_KEY и пр.
npm install
npm run dev

# Backend (Redis + MinIO)
cd redis-api
npm install
node server.js
```

## 🔑 Переменные окружения (.env)

| Переменная | Описание |
|---|---|
| VITE_QWEN_API_BASE | URL Qwen3 API |
| VITE_QWEN_API_KEY | Ключ Qwen3 |
| VITE_ALEMLLM_API_BASE | URL AlemLLM |
| VITE_ALEMLLM_API_KEY | Ключ AlemLLM |
| VITE_BACKEND_URL | URL backend Redis-API (default: localhost:4000) |
| VITE_NOCODB_URL | URL NocoDB |
| VITE_NOCODB_TOKEN | Токен NocoDB |
| VITE_NOCODB_TABLE_ID | ID таблицы NocoDB |
| VITE_FORMBRICKS_* | Настройки Formbricks |
| VITE_MINIO_BUCKET | Bucket MinIO |
